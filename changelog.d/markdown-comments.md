### Changed
- Comments on a Markdown file's preview and on the agent's replies are made by selecting text in an
  app-wide comment mode: one switch, in the file viewer's header and beside Find in the chat, for
  the preview, the code view and the chat. A selection shows a Comment button that opens the
  comment field (or opens the field at once, as Settings choose). Comments show as cards in the
  margin or as counts beside the lines, each with its own soft highlight, darker where comments
  overlap. Every comment setting is on one Settings page, Comments. On a phone or tablet the app's
  own selection and a comment sheet replace the system's menu. Leaving a comment field (Escape, a
  click elsewhere) saves what was typed, in the code view too, and the agent gets the selected
  words instead of the whole source line.
