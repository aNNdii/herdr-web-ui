### Added
- "Hide viewed files" in the review's Changed files list: viewed files and folders left without a
  file drop out, the file being shown stays until another is chosen, and a note with "Show viewed
  files" appears once every file is viewed. The choice is remembered on this device.
- The review's file tree column can be dragged wider or narrower, or resized with the arrow keys
  (double-click resets); the width is remembered on this device. Phones have no handle.
- Hovering a row in the review's tree shows its full path; folder rows in the Files dialog's
  Changes list show theirs too.

### Changed
- Long paths in the review's tree and the Changes list keep the part that tells them apart: a
  folder chain shortens its first folders to one letter before the deepest one, and a file name
  keeps its end and extension.
- A viewed file keeps its check in the review's tree when its name is shortened, and its icon and
  name fade, keeping their colours.
- The Viewed button sits last among a file's tools in the review.
- The review's tree indents each level less.

### Fixed
- An image, PDF or other file the review shows in its file viewer no longer ends in "This file
  can't be shown." once it has loaded.
- A file marked viewed in the review shows its check in the tree at once, not only after another
  file is chosen.
